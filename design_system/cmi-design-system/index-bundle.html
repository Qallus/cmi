01 · Foundations

Brand

The mark is a hexagonal lattice — six structural nodes forming a single bond. It reads as "constructed matter" at any scale. Do not redraw it; use the supplied lockups.

Reversed · DarkLogo

Clear space

Minimum size
Mark: 16px web · 6mm print. Wordmark: 80px web · 22mm print.
Don't
Don't recolor outside system, distort, or place on busy imagery without scrim.

15 · Resources

Usage guidelines

Copper is structural
Reserve the accent for the single highest-priority action in any view. Two coppers in one frame is one too many.
Density follows context
Marketing breathes: 80px stack rhythm. CRM works: 24–32px stack rhythm. Both share the same scale tokens.
Photography over illustration
Use project photography. Avoid generic illustration; the work is the visual proof.

# CMI Feature Docs

Copy-paste-ready feature + replication guides for the major CMI dashboard
systems. Each doc covers the full scope: features, Supabase data model
(tables/fields/enums), API routes, data layer, UI/components, integrations/env,
and a replication checklist.

- [Project Management (Gantt)](./project-management.md) — Gantt + Kanban/List/
  Table/Calendar/Templates/My-Tasks views, the per-bar FAB action dock,
  dependencies, construction templates, and asset associations.
- [Digital Business Cards](./digital-business-cards.md) — card builder, public
  `/c/{slug}` page, splash modes, lead capture + conversion, automations,
  analytics.
- [Recording Studio](./recording-studio.md) — audio recording/upload,
  Whisper transcription, Bolt AI summaries, multi-recordings, 4 views.
- [Booking Tool](./booking-tool.md) — appointment types, availability engine,
  public booking flow, event pages, admin dashboard, and side-effects.
